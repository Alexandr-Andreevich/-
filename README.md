# Исследование применения алгоритма Proximal Policy Optimization (PPO) для управления роботом-манипулятором в условиях неопределенности.
  
  Цель работы — исследовать эффективность алгоритма PPO для управления роботом-манипулятором (среда Pusher-v5 из MuJoCo) в условиях стохастичности и неопределённости среды.
  
  В ходе работы реализованы: подготовка среды, настройка гиперпараметров PPO, обучение агента, оценка по метрикам (средняя награда, дисперсия), визуализация траектории и сохранение видео лучшего эпизода. Особое внимание уделено воспроизводимости, оптимизации под ограничения Google Colab (RAM/GPU) и наглядной демонстрации результатов.

Ссылка на работу в Google Collab: https://colab.research.google.com/drive/14FjkgJqFGE35ZHLEjBNQ7RyINH6rqiy6?usp=sharing

Для проверки кода и записи видео с результатом обученного агента потребуется запустить проект на локальном компьютере.

Так же, в файлах проекта прилагается видео для демонстрации работы агента Preview Pusher-v5 PPO.mp4

# Запуск проекта на ПК
  - скачать папку Pusher-v5 PPO.zip
  - открыть проект в VSCode или Pycharm
  - запустить терминал
  - создать виртуальное окружение командой: py -m venv .venv
  - запустить виртуальное окружение командой: .venv\Scripts\activate
  - установить необходимые библиотеки для работы командой: py -m pip install --upgrade gymnasium mujoco stable-baselines3 imageio matplotlib seaborn plotly tqdm pandas
  - запустить файл main.py

После обучения модели, появится видео с лучшим эпизодом агента.
